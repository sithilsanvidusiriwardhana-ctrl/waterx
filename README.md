# waterX

Smart Plant Water Management System frontend demonstration.

## Run the dashboard

```powershell
cd frountend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The dashboard uses local mock data only; new plants are kept in React state for the current session and are not persisted.

Production checks and startup:

```powershell
npm run lint
npm run build
npm start
```
